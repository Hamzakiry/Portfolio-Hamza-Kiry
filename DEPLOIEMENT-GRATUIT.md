# Adresse gratuite pour le portfolio de Hamza Kiry

Adresse souhaitée : https://hamzakiry-portfolio.vercel.app/

Cette adresse est une proposition, pas une adresse réservée. Sa disponibilité ne peut être confirmée qu'au moment de la création du projet Vercel. Aucun domaine payant, abonnement ou changement du site actuel n'a été effectué.

## Préparation réalisée

- Configuration Vercel dans vercel.json, en conservant React et les composants actuels.
- Construction à la racine du domaine : images, CV, certificats et navigation compatibles.
- Pré-rendu de l'accueil, URL canonique, données structurées, partage, sitemap et robots adaptés au domaine de destination.
- La construction GitHub Pages par défaut conserve son adresse et ses chemins actuels.

## Publication à terminer

L'accès à vercel.com a été refusé par le contrôle d'autorisation du navigateur. Aucun accès de contournement ni envoi vers Vercel n'a été utilisé.

1. Autoriser l'accès à Vercel et ouvrir le compte personnel du propriétaire.
2. Choisir le plan Hobby gratuit et créer un projet nommé hamzakiry-portfolio. Si ce nom n'est pas disponible, choisir une autre adresse avec le propriétaire.
3. Importer le dépôt Hamzakiry/Portfolio-Hamza-Kiry. La configuration de build est déjà dans vercel.json.
4. Déployer et vérifier l'adresse attribuée, les images, les deux CV, les dix PDF de certifications, FR/EN et la page Contact.
5. Si Vercel attribue une autre adresse, mettre PORTFOLIO_SITE_URL à jour avant la publication finale.
6. Après confirmation du nouveau site, ajouter sa propriété Search Console, la valider et soumettre son sitemap. Décider ensuite des redirections et du changement d'URL canonique sur l'ancien site, afin de ne pas annoncer une migration avant que la destination existe.

Le domaine .vercel.app est un sous-domaine gratuit, pas un domaine .io acheté. Un compte Vercel ou une confirmation de ses conditions peut nécessiter l'intervention du propriétaire. Aucun classement Google n'est garanti par ce changement d'adresse.

## Nom et icône dans Google — correction du 24 octobre 2026

Le site dispose d’une icône portrait PNG 96 px, d’un favicon ICO, d’icônes mobiles et du nom « Hamza Kiry Portfolio » dans le manifeste, Open Graph et les données WebSite. Google gère le nom du site au niveau du domaine ou sous-domaine, pas du sous-dossier GitHub Pages. La nouvelle adresse de production Vercel doit être ajoutée comme propriété dans Search Console, puis son sitemap.xml soumis et sa page d’accueil inspectée. Cela ne garantit ni le nom affiché ni le classement.

La compilation Vercel utilise désormais VERCEL_PROJECT_PRODUCTION_URL pour la canonical, Open Graph, le graphe JSON-LD, le sitemap et robots.txt. L’ancienne adresse Vercel supposée a été retirée. Si les variables système sont désactivées, les activer dans Vercel ou définir PORTFOLIO_SITE_URL avec l’adresse de production réelle. Le build standard GitHub Pages est conservé. La validation locale du build a réussi ; le déploiement Vercel et la nouvelle propriété Search Console restent à vérifier.
